# Fancy Components

Text Highlighter and Letter Swap Forward are adapted in `src/components/FancyText.jsx` from Fancy Components by Daniel Petho. Adaptations remove Tailwind and TypeScript dependencies, use the existing editorial colors, support keyboard-triggered nav motion, and respect reduced motion.

Original sources:
- https://github.com/danielpetho/fancy/blob/main/src/fancy/components/text/text-highlighter.tsx
- https://github.com/danielpetho/fancy/blob/main/src/fancy/components/text/letter-swap-forward-anim.tsx

## Lecture 6 practice page

`public/practice/lecture6.html` contains native adaptations of the same Text Highlighter and Letter Swap treatments, with the MIT license included inside the standalone HTML. It also embeds DM Sans and IBM Plex Mono for offline use; their SIL Open Font License 1.1 notices are included in that file. No new animation dependency is introduced.
