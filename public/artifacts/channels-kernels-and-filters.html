Channels, Kernels, and Filters:
Three Different Jobs

A channel holds data. A kernel holds weights. A filter uses those weights to make a new channel. Start with one little patch, then connect it to Lecture 3’s diagram.

Channel · Kernel · Filter · Count & practice

Goal: explain each term and count a layer’s weights without confusing input channels with filters. Work through one section at a time; try each question before revealing its answer.

1 · A channel is one grid of data values

A channel is one height-by-width grid within an image or a layer’s data. An RGB image has three aligned grids: red intensity, green intensity, and blue intensity. At the same pixel position, those three values together specify its color. “Three channels” means three numbers per position, not three separate photographs. [Lecture3, slide 17]

A tensor is an array with named dimensions. Ignoring the batch of images, write the input shape as (cᵢ, hᵢ, wᵢ): channels, height, width. A 5×5 RGB image therefore contains 3×5×5 = 75 data values.

Inside a convolutional neural network, later channels hold computed responses rather than RGB intensities. One such output grid is a feature map; its numbers are activations. It may respond strongly to some patterns, but it need not have a tidy human name. [CS231n, Convolutional Layer]

A channel tells you what values exist at every location.

Pause: does a 5×5 RGB image have 3 channels or 25?

Three. Twenty-five is the number of spatial positions in each channel. Channels are a different dimension from height and width.

2 · A kernel is a small grid of weights

A kernel, using slide 17’s spatial convention, is a small grid of weights: coefficients that multiply nearby input values. A 3×3 kernel has nine weights. Place it over a matching 3×3 input patch, multiply corresponding entries, then add all nine products to get one number. Moving it across the image repeats that calculation at other locations. [Lecture3, slides 13–14]

Here is a constructed patch. Its center is 5 and its eight neighbors are 1. The identity kernel keeps the center, giving 5. The blur kernel uses nine weights of 1/9, giving (5+8)/9 ≈ 1.44. The edge kernel has center weight 8 and eight weights of −1, giving 8×5−8 = 32. These are the kernels shown on slide 14; these input numbers are our teaching example.

Convolution is the sliding weighted-sum operation described in the lecture. Stride is the step size between positions; padding adds a border so the kernel can reach edge positions. [Lecture3, slides 12, 14, 22] The weights are reused at every position; moving the kernel does not create new parameters.

3 · A full filter combines the input channels into one output channel

A filter is the complete set of weights for one output channel. In an ordinary dense RGB convolution, one filter contains three spatial kernels: one for red, one for green, one for blue. Each kernel computes a contribution at the same location. Add those three contributions, plus one optional bias (a learned offset), to obtain one output value. Repeat across positions to fill one output channel. [Lecture3, slide 17]

For a simple constructed example, let three 1×1 kernels have weights 2, −1, and 0.5. At a pixel with R=10, G=4, B=2, and bias=1:

output = 2×10 − 1×4 + 0.5×2 + 1 = 18

The three input contributions merge into one number. A second filter has its own weights and produces a second channel. Slide 17’s four filters therefore produce four channels, even though the input has three. The next layer receives those four maps as its input channels.

Why the terms sound interchangeable: “kernel” and “filter” are often used for the same whole weight object. For counting here, “spatial kernel” means one k×k slice, and “full filter” means all input-channel slices for one output. For a one-channel input, those objects coincide.

PyTorch’s Conv2d uses a sum over input channels and calls the unflipped operation cross-correlation. Its kernel_size specifies spatial dimensions. With groups=1, every filter sees every input channel; grouped or depthwise layers change that connectivity. [Conv2d, formula & groups]

4 · Count filters, then kernels, then weights

For four 3×3 filters receiving three input channels, the weight tensor is W=(4,3,3,3). Read its dimensions as output channels, input channels, kernel height, kernel width. There are 4 filters, 12 spatial kernels, and 108 weights. Including one bias per output channel gives 112 parameters. [Lecture3, slides 17, 38–40]

As a constructed shape example, apply this layer to a 5×5 RGB image with stride 1 and no padding. A 3×3 window fits three times along each axis, producing a (4,3,3) output: 36 activations. Its 108 weights are a separate count.

Predict, then check. For that layer, how many weights are there, excluding biases?

What changes if there are 8 filters instead of 4?

There are 8 output channels, 8×3 = 24 spatial kernels, and 8×3×3×3 = 216 weights. Input channels stay at 3.

Does a larger image require more weights in this same layer?

No. The same weights visit more positions, producing more activations and doing more arithmetic. Spatial size does not enter the weight formula.

Describe the data grid, the weight grid, and the complete set of weight grids that produces one output. Then redo the count with 2 input channels, 5 filters, and 3×3 kernels: 5×2×9 = 90 weights.

Pixel values are part-of an input channel; convolution requires input channels and filters; spatial kernels are part-of a filter; convolution enables output channels; output channels enable the next layer; filters are measured-by weight count. [Lecture3, slides 14–20]

What this does not show

The identity, blur, and edge weights are fixed teaching examples. CNN weights are normally learned; filters need not become clean edge detectors. This page covers dense 2D convolution, not the grouped/depthwise counting rules from slides 23–24. It does not demonstrate training or predict hardware speed.
