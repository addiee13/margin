Neural Network Pruning: Cutting a Model Without Killing It

Most weights in a trained network contribute almost nothing. Pruning removes them and leaves a smaller, faster model that is nearly as accurate. Doing it well means answering four questions: what unit to cut, which ones to cut, how much to cut in each layer, and how to recover afterward. This page walks through all four, with small labs where you can try each idea yourself.

1 · Pruning is an optimization problem with a budget

The slides start with an analogy: pruning is like trimming a tree. You cut away the branches that are not pulling their weight, and the tree keeps its shape, stays healthy, and grows back stronger. In a network, the branches are weights. The human brain does the same thing: it first grows many connections, then removes the less useful ones as it develops. [L4–5, intro slides]

You can prune two kinds of things. Synapses are the weights (parameters) on the connections. Neurons are the activations: the outputs of the units themselves. Removing synapses means fewer parameters and less computation. Removing neurons means fewer activations and less data movement, which matters because moving data in memory costs far more energy than doing arithmetic. [L4, Memory is expensive]

Formally, pruning finds the best pruned weights WP under a hard budget:

arg minWP L(x; WP)   subject to   ‖WP‖0 < N

Here L is the training objective, x is the input, W are the original weights and WP the pruned ones. ‖·‖0 counts the nonzero entries, and N is the target number of nonzeros. Out of all possible weight values, find the ones that make the prediction error smallest, but you may keep at most N of them nonzero. Every method below is a different way to approximate this problem, because solving it exactly would mean trying every possible subset of weights. [L5–6, formulation]

2 · Granularity trades flexibility for real speed

Granularity is the unit you remove: a single weight, a group of weights, or an entire channel or filter. Start with a 3×3 weight matrix. Fine-grained (unstructured) pruning may zero any entry, for example keeping only w11, w13, w22, w31 and w33. Coarse-grained (structured) pruning removes whole rows, so what remains is simply a smaller dense matrix. [L5, 2D weight matrix]

The spectrum for convolutional layers

A conv weight tensor has four dimensions: output channels co, input channels ci, kernel height kh and kernel width kw. The slide's example uses 3×3 kernels with ci = 2. Going from irregular to regular, the common granularities are: fine-grained (any single weight), pattern-based (fixed shapes, "like Tetris"), vector-level (a row of a kernel), kernel-level (a whole kh×kw kernel) and channel-level (a whole channel). N:M sparsity. In every M contiguous elements, N are pruned. The classic case is 2:4, which is 50% sparsity. There are C(4,2) = 6 ways to choose which two survive, so each kept value needs only a 2-bit index. The compressed matrix stores half the values plus those indices. Channel pruning. Removing whole channels gives a direct speedup, because the network simply has fewer channels, but the compression ratio is smaller. Pruning every layer by the same 0.3 ("uniform shrink") does worse than giving each layer its own sparsity, for example 0.5, 0.3, 0.7, 0.2, 0.3. On ImageNet, channel pruning with AMC reaches higher accuracy at every latency than uniform scaling does. How to find those per-layer numbers is section 5. [He et al. 2018, Fig. 1]

3 · To pick weights, ask "how much would the loss notice?"

The rule: the less important the removed parameters are, the better the pruned network performs. Try it on one neuron: y = ReLU(10x0 − 8x1 + 0.1x2). If you must delete one weight, which one? [L5, Selection of synapses]

Answer

The 0.1. Removing it changes y the least, because its input is scaled down to almost nothing. That intuition is the whole idea behind magnitude-based pruning.

Method 1 · Magnitude-based (heuristic)

Weights with larger absolute values are treated as more important. For element-wise pruning, importance = |w|. For structured pruning, you measure the magnitude of a whole group S (such as a row) with the Lp-norm: [Han et al., §3]

‖W(S)‖p = ( Σi∈S |wi|p )1/p

Use p = 1 for the row-wise L1 norm (Σ|wi|) and p = 2 for the L2 norm (√Σ|wi|²).

With the slide's example [[3, −2], [1, −5]], element-wise pruning keeps 3 and −5. Row-wise L1 gives the rows importance 5 and 6, and L2 gives √13 and √26. Either norm kills row 0, leaving [[0, 0], [1, −5]]. Now change −2 to −4 and see whether L1 and L2 still agree. [L5, Method 1 examples]

Method 2 · Scaling-based (for filters)

Each filter (output channel) of a conv layer gets a trainable scaling factor γ, which multiplies that channel's output. After training, channels with small γ are pruned. In the slide, filters with factors 0.10 and 0.29 are removed, while those with 1.17, 0.82 and 0.56 survive. Instead of guessing importance afterward, the network learns it during training. [Liu et al., §3]

Method 3 · Second-order (Optimal Brain Damage)

The goal here is to minimize the increase in loss caused by pruning. Expand that increase with a Taylor series: [LeCun et al., §2]

δL = L(x;W) − L(x;WP = W − δW) = Σi giδwi + ½Σi hiiδwi2 + ½Σi≠j hijδwiδwj + O(‖δW‖3)

where gi = ∂L/∂wi and hij = ∂²L/∂wi∂wj. Optimal Brain Damage assumes three things, and each one deletes a term:

AssumptionTerm removed
L is nearly quadraticO(‖δW‖³), the last term
Training has convergedΣ giδwi, the first-order term (the gradient is about 0)
Deleting each parameter has an independent effectThe cross terms hij, i ≠ j

δLi = L(x;W) − L(x;WP | wi = 0) ≈ ½ hii wi2

This is the estimated increase in loss if wi is set to zero. Build the intuition: if every hii were equal, ranking by ½hiiwi² would be the same as ranking by |wi|. Magnitude pruning is the special case that ignores curvature. OBD's extra contribution is noticing that a small weight sitting in a steep direction of the loss can matter more than a large weight in a flat one.

4 · To pick neurons, watch them while they work

Removing a neuron removes a whole row of the weight matrix in a linear layer, or a whole channel in a conv layer. Neuron pruning is coarse-grained weight pruning. The rule is the same as before: the less useful the removed neurons are, the better the pruned network performs. [L5–6, Selection of neurons]

Percentage-of-zero (APoZ)

ReLU outputs zero for every negative input. A channel that is almost always zero is barely contributing. The Average Percentage of Zeros (APoZ) of a channel counts its zero activations over a batch. The smaller the APoZ, the more important the neuron. [Hu et al., §3]

One practical catch: APoZ depends on data, so you must actually run a few inferences to measure it. Weight magnitude, by contrast, can be read straight from the model file. [L5, APoZ]

Regression-based (layer reconstruction)

Instead of tracking the network's final loss L(x; W), this method minimizes the reconstruction error of one layer's outputs. That is a smaller, local problem. Split the layer's matrix product by input channel: [He et al. 2017, §3.1]

Z = XWT = Σc=0ci−1 XcWcT

arg minW,β ‖Z − Ẑ‖F2 = ‖Z − Σc βcXcWcT‖F2   s.t.   ‖β‖0 ≤ Nc

β is a coefficient vector of length ci that selects channels: βc = 0 means channel c is pruned. Nc is the number of nonzero channels. Solve it by alternating: fix W and solve for β to choose channels, then fix β and solve for W to minimize the reconstruction error. In other words, after removing channels, the remaining weights adjust to make up for them.

5 · Each layer needs its own ratio

Non-uniform pruning beats uniform shrinking because layers differ in sensitivity. Some, like the first layer, are fragile; others are highly redundant. [He et al. 2018, §1]

Sensitivity analysis (VGG-11 on CIFAR-10)

  1. Pick a layer Li.
  2. Prune only that layer, at ratios r ∈ {0, 0.1, …, 0.9} (or other strides), and record the accuracy drop ΔAccri.
  3. Repeat for every layer.
  4. Pick a degradation threshold T that gives the overall pruning rate you want. Each layer's ratio is the largest r whose accuracy stays above T.

Is this optimal? Probably not, because sensitivity analysis tests each layer alone and ignores how layers interact. Pruning L3 changes what L4 receives. Conventionally, filling this gap takes human expertise and many rounds of trial and error. Can we push a button instead? [L6, Finding pruning ratios]

AMC: pruning as reinforcement learning

AMC (AutoML for Model Compression) replaces the human with an agent that works through the network one layer at a time. [He et al. 2018, §3]

  • Action is a continuous ratio, which is why they use DDPG: it supports continuous actions.
  • Reward R = −Error if the result satisfies the constraints, and −∞ if not. A variant uses −Error·log(FLOP).
  • Latency constraints are handled with a pre-built lookup table (LUT) of measured layer latencies.

On ResNet50, AMC finds sparser layers than a human expert. Density is the share of nonzero weights, so lower is better:

NetAdapt: a rule-based iterative method

The goal is the same: find per-layer ratios that meet a global resource constraint such as latency or energy. The difference is that NetAdapt gets there with a simple greedy loop instead of a learned agent: [Yang et al., §3]

  1. Each iteration aims to cut latency by a manually chosen amount ΔR.
  2. For each layer Lk (A to Z), prune just that layer until its latency reduction meets ΔR, using a pre-built lookup table.
  3. Short-term fine-tune each candidate (10k iterations) and measure its accuracy.
  4. Keep the candidate with the highest accuracy.
  5. Repeat until the total latency reduction satisfies the constraint, then run a long-term fine-tune to recover accuracy.

A bonus: every iteration produces a model, so you get a series of models with different costs (#models = #iterations). On the latency-accuracy plot, NetAdapt is 1.7× faster with 0.3% higher accuracy than the Multipliers baseline, and 1.6× faster with 0.3% higher accuracy than MorphNet.

6 · Fine-tuning turns a damaged model into a good one

Back to your opening guess. On AlexNet, pruning without retraining loses about 0.5% accuracy at 50% pruned and over 4% at 80%. The weight histogram shows why: pruning cuts out the band of weights near zero. If you then retrain the remaining weights, the accuracy comes back, and you can push to roughly 90% pruned with no loss. [Han et al., Fig. 5]

  • The learning rate for fine-tuning is usually 1/100 or 1/10 of the original. The network is already close to a good solution and only needs small corrections.
  • Iterative pruning treats one prune plus fine-tune as an iteration and raises the target sparsity each time (50%, then 70%, …).
  • On AlexNet, iterative pruning boosts the pruning ratio from 5× to 9× compared with one aggressive pruning step.

So the answer to the opening question is closer to 90%, provided you prune gradually and retrain in between.

Exam check: try before you open

  1. Write the pruning objective and name every symbol.
    Answer

    arg minWP L(x; WP) s.t. ‖WP‖0 < N. L is the training loss, x the input, WP the pruned weights, ‖·‖0 the count of nonzeros, and N the target number of nonzeros.

  2. Prune [[4, −1], [−2, 3]] by 50% with row-wise L2.
    Answer

    Row norms are √17 and √13, so prune row 1: [[4, −1], [0, 0]]. Element-wise pruning would instead keep 4 and 3.

  3. Why does fine-grained pruning get high compression but little real speedup?
    Answer

    The zeros are scattered, so dense hardware still processes the full matrix shape. Turning sparsity into speed needs index handling or special hardware. Structured pruning leaves a smaller dense matrix instead.

  4. How many index bits does each kept value need in 2:4 sparsity, and why?
    Answer

    2 bits: each kept value records its position among the 4 slots. There are C(4,2) = 6 possible patterns per group.

  5. State the three OBD assumptions and the resulting formula.
    Answer

    The loss is nearly quadratic (drop the cubic term), training has converged (drop the gradient term), and deletions are independent (drop the cross terms). The result is δLi ≈ ½ hii wi².

  6. A channel has APoZ 14/32. Another has 11/32. Which do you prune?
    Answer

    The 14/32 channel. A higher APoZ means it outputs zeros more often, so it is less important.

  7. What does the AMC reward return when the constraint is violated, and why use DDPG?
    Answer

    It returns −∞. DDPG is used because the action, a pruning ratio in [0,1), is continuous.

  8. What is the main weakness of sensitivity analysis, and which methods address it?
    Answer

    It ignores interactions between layers. AMC and NetAdapt search over the whole network, through RL or a greedy loop with short fine-tuning.

What this does not show
