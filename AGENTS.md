# Agent instructions

Use standard shell commands and native agent tools directly, without command-rewriting wrappers.

Before staging, committing, pushing, or deploying changes, read and follow [docs/deployment.md](docs/deployment.md). It defines focused commits, safe branch handling, release authorization, and the evidence required to report a successful deployment.

For interface changes, follow [docs/design.md](docs/design.md) and [docs/product.md](docs/product.md). Preserve the original artifacts and their interactive labs; publication enhancements belong in the app or distribution build.
